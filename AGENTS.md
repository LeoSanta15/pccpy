# AGENTS.md

Las instrucciones para agentes de IA de este repositorio están en [`CLAUDE.md`](CLAUDE.md):
comandos, definición de "terminado", reglas (R-01..R-16) y deuda conocida.

Resumen mínimo: `make check` debe pasar antes de dar una tarea por terminada;
el tag y el release los crea el usuario; lee `docs/retrospectiva/BUG_CATALOG.md`
antes de tocar validación de entrada, imports opcionales, autodoc o releases.
